AYRA GLOW - website guide

RUN: Extract the ZIP, then open index.html in a browser. For best results, use VS Code Live Server.

BRAND: Ayra Glow. The website uses a soft baby-pink palette.

UPLOAD YOUR OWN PRODUCTS: Open the ADD PRODUCT link in the navigation (admin.html). Enter a name, category, price, description and upload a product image. Products are saved in the browser's localStorage and appear in the shop automatically. Use an image under 2 MB.

IMPORTANT: Product uploads are stored only in the browser/device where they are added. This is a front-end demo and does not sync products to other devices or provide secure admin login. For a live multi-user store, connect a backend/database and authentication.

PRODUCTS: Existing sample products are in js/products.js.
COLORS: Edit CSS variables at the top of css/style.css.
